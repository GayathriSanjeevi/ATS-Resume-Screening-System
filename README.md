# ATS-Resume-Screening-System

An AI-powered Resume Screening and Skill Matching System built using Python, NLTK, Scikit-learn, and Streamlit.

The application compares a candidate's resume with a job description and provides:

- ATS Similarity Score
- Skill Match Percentage
- Matching Skills
- Missing Skills
- Skill Recommendations

The system is designed for Data Science and Analytics roles.

## Features

- Upload resumes in PDF and DOCX formats
- Extract and process resume text automatically
- NLP-based text preprocessing using NLTK
- ATS Similarity Score calculation using TF-IDF and Cosine Similarity
- Skill extraction from resumes and job descriptions
- Matching skills identification
- Missing skills detection
- Skill Match Percentage calculation
- Recommended skills for improvement
- Interactive Streamlit dashboard with tabs and progress bars

## Project Workflow

1. Upload Resume (PDF/DOCX)
2. Extract Resume Text
3. Preprocess Resume and Job Description using NLP
4. Calculate ATS Similarity Score
5. Extract Skills from Resume and Job Description
6. Identify Matching Skills
7. Identify Missing Skills
8. Calculate Skill Match Percentage
9. Generate Skill Recommendations
10. Display Results through an Interactive Dashboard
